### Задание 3
```
int a =1 , b =2;
int c =a +++ b;
```
* значения переменных после исполнения этой программы: a = 2, b = 2, с = 3;

* Разбиение на токины:
* ключевые слова: int
* идентификаторы: a, b
* литералы: 1, 2
* операторы: ++, +, = 

* Так как в C++ нет "+++", компилятор разбивает эти 3 плюса на существующие операторы "++" и "+". Компилятор забирает максимально длинный токен, поэтому из трех плюсов он сначала собирает ++ к переменной a,
* а оставшийся один + идет как обычное сложение с b. Оператор "++" - постфиксный инкремент(Сначала старое значение используется в выражении, а потом переменная увеличивается на 1), значит, для вычисления берется
* старое значение a = 1, из-за чего c = 1 + 2 = 3. И только после этого переменная a увеличивается, то есть в итоге a = 2, а b = 2, с = 3.

* Да, изменить разбиение этой программы на токены, вставляя пробелы можно. Пробел не является токеном, но он служит разделителем, который указывает компилятору, где заканчивается один токен и начинается другой.
* Это меняет смысл программы и результат вычислений. Если поставить пробел после первого плюса (c = a+ ++b;) компилятор разобьет строку на токены c = a + ++ b;. Теперь ++ относится к переменной b и становится
* префиксным инкрементом. Сначала переменная b увеличивается на 1 и становится равной 3. Затем новое значение используется в сложении c = 1 + 3 = 4. Переменная a при этом не меняется. Тогда результат будет
* a = 1, b = 3, c = 4

### Задание 4
* Круглые скобки являются оператором, когда используются для вызова функции
* Квадратные скобки являются оператором в случае индексации, когда обращаемся к элементу уже созданного массива по его индексу

* Пример, где () оператор: int s = sum(2, 3); - вызов функции sum с двумя аргументами
* Пример, где () не оператор: int a = (2 + 3) * 2; (2 + 3) - нужно для того, чтобы изменить порядок выполнения операций. Поэтому () группируют выражение
* Пример, где [] оператор: int a[5] = {1, 2, 3, 4, 5}; int x = a[2]; Тут a[2] означает взять третий элемент массива a
* Пример, где [] не оператор: int a[5]; Здесь [5] означает, что создаётся массив из 5 элементов.

### Задание 5
```
print (* map ( sum , zip (
     *[ map ( int , input (). split ()) for i in (1 ,2 ,3)]
     )))
```
* ключевые слова: for, in
* идентификаторы: print, map, sum, zip, int, input, split, i
* литералы: 1, 2, 3
* операторы: *

* идентификатор переменной - i
* имена функций: print, map, sum, zip, int, input
* имя метода: split

* print(*map()) — выводит результат на экран. Параметр: результат функции map, распакованный с помощью *
* map(sum, zip()) — применяет функцию sum к каждому элементу, полученному от zip. Параметры: sum, zip()
* sum() — вычисляет сумму элементов последовательности. Параметр: последовательность чисел
* zip(*[]) — объединяет три последовательности по соответствующим позициям. Параметры: три последовательности map(int, input().split())
* map(int, input().split()) — преобразует введённые строки в целые числа. Параметры: int, результат input().split()
* input() — считывает строку с клавиатуры 
* split() — разделяет введённую строку на отдельные элементы

* Сначала программа три раза считывает строки благодаря циклу for. Функция input() получает строку, метод split() разделяет её по пробелам, а map(int, ...) преобразует полученные строки в целые числа.
* Затем zip() объединяет три последовательности по одинаковым позициям, то есть формирует столбцы. После этого map(sum, ...) вычисляет сумму каждого столбца. 
* В конце print() выводит полученные суммы, а оператор * используется для распаковки результатов.

### Задание 6
* Однострочные "//" — компилятор игнорирует всё, что идёт после этих символов и до конца текущей строки.
* Многострочные (блочные, /* ... */) — компилятор игнорирует всё, что находится между открывающим /* и закрывающим */ символами

* cout <<"Hello /* Это комментарий */ world";  - верный 
* Символы /* и */ находятся внутри кавычек строкового литерала. Компилятор воспринимает их не как комментарий, а как обычную часть текста. На экран выведется строка: Hello /* Это комментарий */ world.

* // /*
* Это комментарий
* /
* Неверный, потому что  Первая строка начинается с однострочного комментария //. Из-за этого открывающий блочный комментарий /* закомментирован и не работает. Для компилятора вторая строка
* "Это комментарий" это обычный код, который он пытается скомпилировать и выдаёт ошибку синтаксиса.

* /* Я комментирую программы /* комментарий */ */
* Неверный, потому что  C++ многострочные комментарии нельзя вкладывать друг в друга. Компилятор видит первый /*, считает всё текстом комментария, встречает первый же закрывающий */ и завершает комментарий. 
* Оставшийся в конце символ */ оказывается вне комментария, ломает синтаксис и вызывает ошибку.

* // Я комментирую программы /* комментарий */ - верный
* Строка начинается с //. Компилятор мгновенно игнорирует всю строку целиком до самого конца. Находящиеся внутри символы /* и */ никак не учитываются.

* /* Я комментирую свои программы
* // Это комментарий до конца строки */
* */
* Неверный, потому что  Первый блочный комментарий открывается на первой строке через /*. На второй строке символы // просто считаются частью закомментированного текста. Далее на второй строке встречается
* закрывающий символ */, который закрывает самый первый комментарий. Из-за этого третья строка, состоящая из одинокого */, оказывается обычным кодом C++ и вызывает ошибку компиляции.

### Задание 7
* Как видно из правил, есть 3 основных вида инструкций циклов.
* Первый вид — цикл while, который соответствует строке правила: while ( condition ) statement. Формат записи: ключевое слово while, затем в круглых скобках указывается условие condition, после чего записывается инструкция statement.
* Условие проверяется перед выполнением тела цикла. Если условие истинно, инструкция выполняется. После этого условие проверяется снова.
* Пример программы:
```
int x = 1;
while (x < 1000) {
    cout << x << endl;
    x *= 2;
}
```
* В данном примере условием является x < 1000, а инструкцией является блок команд внутри фигурных скобок.

* Второй вид — цикл do-while, который соответствует строке правила: do statement while ( expression ) ; Формат записи: сначала ключевое слово do, затем инструкция statement, после неё ключевое слово while и в круглых скобках условие expression. В конце ставится точка с запятой.
* В отличие от while, в цикле do-while инструкция сначала выполняется, а условие проверяется после её выполнения. Поэтому тело такого цикла выполняется как минимум один раз.
* Пример программы:
```
int x = 1;
do {
    cout << x << endl;
    x++;
} while (x < 5);
```
* В данном примере сначала выводится значение x и увеличивается на единицу, а затем проверяется условие x < 5.

* Третий вид — цикл for. В стандарте для него приведены две формы записи. 
* Обычный цикл for. Строка правила: for ( init-statement conditionopt ; expressionopt ) statement
* Ключевое слово for, в круглых скобках начальная инструкция, условие и выражение изменения. Далее — тело цикла.
* Пример:
```
for (int i = 0; i < 10; i++) {
cout << i;
}
```
* Здесь int i = 0 - начальная инструкция, i < 10 - условие, i++ - выражение изменения, а блок в фигурных скобках - тело цикла.
* Цикл range-for: Строка правила: for ( for-range-declaration : for-range-initializer ) statement
* Ключевое слово for, в круглых скобках объявление переменной диапазона for-range-declaration, двоеточие и итерируемый диапазон for-range-initializer. Далее тело цикла.
* Пример:
```
int array[5] = {1, 2, 3, 4, 5};
for (int element : array) {
    cout << element;
}
```
* В данном примере int element это переменная, которая по очереди получает значения элементов массива, а array это итерируемый диапазон.

### Задание 8
* В программе значение переменной a вычисляется следующим выражением: a = -x + y * (z - 1);
* Сначала вычисляется выражение в скобках z - 1. Отдельно выполняется унарная операция отрицания -x. Затем выполняется умножение y * (z - 1). После этого выполняется сложение -x + y * (z - 1). 
* В конце полученный результат присваивается переменной a.
* Абстрактное синтаксическое дерево имеет следующий вид:
```
      [=]
     /   \
   (a)   [+]
        /   \
      [-]   [*]
      /     / \
    (x)   (y) [-]
                / \
              (z) (1)
```
* В корне дерева находится оператор присваивания =, так как всё выражение имеет вид a =. Его левым потомком является переменная a, а правым выражение сложения.
* Оператор + имеет два операнда: унарное отрицание -x и результат умножения y * (z - 1). Оператор - в -x является унарным и имеет один операнд x.
* Оператор - в z - 1 является бинарным и имеет два операнда: z и 1.
* Таким образом, дерево отражает структуру исходного выражения и порядок выполнения операций.
