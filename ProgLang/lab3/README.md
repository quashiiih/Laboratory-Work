* Преобразование из вещественных в целочисленные: отсечение дробной части.
* Преобразование с символьными типами: по коду символа.
* При присваивании значение правого операнда приводится к типу левого операнда.

*2. Преобразования при арифметических действиях*
* Если длины обоих типов меньше int то преобразование к int.

* Если оператор требует логического значения, то операнды приводятся к логическому типу (логические операции).

* b получает результат операции x && y. Оператор && — логическим И и возвращает значение типа bool. Поэтому результат true && false равен false, а переменная b имеет тип bool.
* Поэтому программа выводит: 
* i
* b

### Задание 5. **(2)**
*Приведите разумные (логичные) примеры использования в

* 1. Программа с typedef
```cpp
#include <iostream>
using namespace std;

int main() {
    typedef long long ll;
    ll a = 1000;
    cout << a << endl;

```

* typedef используется для создания дополнительного имени существующего типа. 
* ll является другим именем типа long long, поэтому объявление ll a аналогично объявлению long long a.

* 2. Программа с auto
```cpp
#include <iostream>
using namespace std;

int main() {
    auto a = 10;
    auto b = 2.5;
    auto c = 'C';
    cout << a << " " << b  << " " << c << endl;
    return 0;
}
```

* auto позволяет компилятору автоматически определить тип переменной по ее начальному значению.
* Так как число 10 имеет тип int, переменная a получает тип int. Поскольку 2.5 является вещественным числом, переменная b получает тип double. Символ 'C' относится к текстовым символам, поэтому переменная c получает тип char.

* 3. Программа с decltype
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    decltype(a) b = 15;
    cout << b << endl;
    return 0;
}
```

* decltype позволяет получить тип указанной переменной или выражения.
* Так как переменная a имеет тип int, переменная b, объявленная с помощью decltype(a), также имеет тип int.

* 4. Программа с static_cast
```cpp
#include <iostream>
using namespace std;

int main() {
    double a = 2.5;
    int b = static_cast<int>(a);
    cout << b << endl;
    return 0;
}
```

* static_cast используется для явного преобразования значения из одного типа в другой. 
* В данном случае значение типа double преобразуется в тип int. В результате дробная часть отбрасывается, поэтому переменная b получает значение 2.

* 5. Программа с sizeof
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    double b = 2.5;
    char c = 'C';
    cout << sizeof(a) << " " << sizeof(b) << " " << sizeof(c) << endl;
    return 0;
}
```

* sizeof позволяет определить размер переменной или типа в байтах.
* В результате программа выводит количество байт, которое занимают переменные a, b и c в памяти. Этот размер зависит от типа данных. Для переменной a (тип int) обычно выводится 4, для b (тип double) — 8, а для c (тип char) — 1.

* *Объясните работу этой программы, используя правила неявного преобразования типов*
* *Что произойдет, если тип* **int** *заменить на* **short**, а **unsigned int** на **unsigned short**?*

* Код программы
```cpp
#include <iostream>
int main() {
    int a = -1, b = 1;
    unsigned int c = 1;
    std::cout << a * b << std::endl;
    std::cout << a * c << std::endl;
}
```

* В первом выражении a * b обе переменные имеют тип int, поэтому результат тоже будет int: -1 * 1 = -1
* Во втором выражении a * c участвуют типы int и unsigned int. В соответствии с правилами неявного преобразования типов, знаковый тип переменной a (int) приводится к беззнаковому типу (unsigned int). При 32-битном unsigned int число -1 представляется как 4294967295(2^32). Поэтому результат умножения равен 4294967295 * 1 = 4294967295

* Код программы (вместо int, short, вместо unsigned int, unsigned short)
```cpp
#include <iostream>
int main() {
    short a = -1, b = 1;
    unsigned short c = 1;
    std::cout << a * b << std::endl;
    std::cout << a * c << std::endl;
}
```

* В первом выражении a * b обе переменные имеют тип short, но при арифметической операции они автоматически преобразуются к int. Результат вычисляется в типах знаковых целых чисел: -1 * 1 = -1.
* Во втором выражении a * c участвуют типы short и unsigned short. Из-за размера меньше int оба операнда сначала неявно приводятся к знаковому int. Значение -1 сохраняет свой знак, поэтому результат умножения равен -1 * 1 = -1.
* a * b = -1 и a * c = -1, так как в обоих случаях финальные вычисления происходят в рамках знакового типа int.

*Рассмотрите следующий фрагмент программы.*

*Почему изменения порядка действий приводит
к изменению результата? Объясните работу этой программы, используя правила неявного преобразования типов*

* 1 фрагмент программы:
```
int x = 7, y = 4;
long double d = 0.25;
cout << (x / y) / d << endl;
cout << (x / d) / y << endl;
```
* Cначала выполняется x / y. Обе переменные имеют тип int, поэтому выполняется целочисленное деление: 7 / 4 = 1. После этого результат 1 преобразуется в long double и делится на 0.25: 1.0 / 0.25 = 4.0
* Потом выполняется x / d. d имеет тип long double, значение x неявно преобразуется в long double: 7.0 / 0.25 = 28.0. Далее результат делится на y, который также преобразуется в long double: 28.0 / 4.0 = 7.0
* Получаем (x / y) / d = 4; (x / d) / y = 7, потому что в первом случае целочисленное деление выполняется до преобразования в long double, поэтому дробная часть теряется, а во втором случае деление выполняется уже в вещественных числах, поэтому дробная часть не теряется
* 2 фрагмент программы 
```
long a = 200000, b = 200000;
long long c = 200000;
std::cout << (a * b) * c << std::endl;
std::cout << a * (b * c) << std::endl;
```
* В (a * b) * c сначала выполняется умножение двух переменных типа long. Результат 200000 * 200000 = 40000000000 не помещается в long, что приводит к переполнению знакового целого типа и неопределённому поведению.
* В a * (b * c) сначала выполняется умножение long на long long. В соответствии с правилами неявного преобразования long преобразуется в long long, поэтому промежуточный результат вычисляется в типе long long и помещается в него: 200000 * 200000 = 40000000000. Далее выполняется умножение на a, которое также преобразуется в long long. Получается: 200000 * 40000000000 = 8000000000000000
* В итоге изменение порядка операций может менять результат, если при промежуточном вычислении используются разные типы данных или происходит потеря точности либо переполнение.

* Выражение: (x == y) + (x == z) == true
* Операторы == возвращают значения типа bool. Поэтому выражения x == y и x == z могут иметь значения true - 1 или false - 0. Поэтому сумма (x == y) + (x == z) может принимать значения 0, 1 или 2
* При сравнении с true значение true преобразуется в 1, значит всё выражение истинно только в том случае, когда сумма равна 1.
* Это возможно в двух случаях:
* 1) x == y и x != z
```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 3, y = 3, z = 2;
    bool result = (x == y) + (x == z) == true;
    cout << result << endl;
    return 0;
}
```

* 2) x != y и x == z
```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 3, y = 2, z = 3;
    bool result = (x == y) + (x == z) == true;
    cout << result << endl;
    return 0;
}
```

* Таким образом, выражение истинно, когда x совпадает ровно с одной из двух переменных — y или z. В обоих случаях программы выведут 1 (true).
